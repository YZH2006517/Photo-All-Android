# 冲洗引擎与原版 spektrafilm 对照备忘

原版 spektrafilm（GPL-3.0，Python）只作为桌面端的参照，它的代码不进应用。对照工具是 `tools/compare_spektrafilm.py`，要在原版的环境里运行：

```
third_party/spektra-venv/Scripts/python.exe -I tools/compare_spektrafilm.py <输出目录> color films papers couplers gamut glare halation diffusion sharpen
```

运行前要先编出桌面 CLI（`build/desktop/filmsim_cli.exe`，需要在 vcvars64 环境里执行 `cmake --build build/desktop --target filmsim_cli`）。每项测试在输出目录的 `results.jsonl` 里写一行。

## 对照方法

- **色卡：** ColorChecker 24，线性 Rec.2020 输入，比较 CIEDE2000。
- **光晕、扩散：** 暗底上一个亮 6 档、半径 8 像素的光点，画面 2400 像素宽，比较光点周围的径向亮度。
- **锐化：** 一条明暗边缘。
- **两边设置一致：**
  - 原版开黑白校正，白点设为 1.0（与我们相同）；
  - 关自动曝光；
  - 颗粒、光晕、杂散光、色域压缩、锐化默认关，只在测对应环节时打开。

## 已对齐（2026-11-23）

| 环节 | 现状 |
|---|---|
| 色调（灰阶） | 中灰落在原版的实际位置（117.5/255，线性 17.8%），黑白校正同原版 |
| 负片色彩 | 16 个负片片种色卡 ΔE 平均 1.1–2.2 |
| 反转片色彩 | 改用原版的反转片成色剂矩阵，去掉 filmsim 的饱和限制后，4 款平均 1.4–2.6 |
| 成色剂 | 关掉成色剂时两边 ΔE 约 1.0–1.5；长尾扩散（200 µm，6%）已加 |
| 颗粒 | 三层同时显影；20 个片种逐个按原版校准，平均强度差在 3% 以内 |
| 光晕 | 顺序改为先光晕、后扣成色剂抑制；强度和散射按三个亮度的光点拟合 |
| 扩散滤镜 | 柔焦、黑柔、泛光按原版剖面拟合：光点外 2–56 像素，最大偏差分别为 0.05、0.03、0.07 |
| 杂散光、锐化 | 一致 |
| UV / IR 截止滤镜 | 参数 `uv cut` / `ir cut`，默认关，和原版一致；设置的「光学」分组里可调。拉满时 UV 截止让色卡平均变化 ΔE 0.5（主要是红、品红），IR 截止几乎无影响（0.03） |

## 待修（之后再做）

1. **色域压缩：** 打开色域压缩后，色卡平均多出 0.4–0.6 的 ΔE，几乎全在深蓝色块（Portra 4.1，Velvia 5.5）。我们用 OkLab，并且只压超出白的亮度；原版用 CAM16-UCS。这基本是风格差异，原版对饱和蓝的色相保持略好。
   - 改法：在 `encode.comp` 里实现 CAM16-UCS 的色度压缩，保留我们「白以下亮度不动」的做法。代价是每个像素的计算更重。
2. **单个片种的残差**（色卡单块最大 ΔE 在 5 左右）：
   - Kodachrome 64：平均 2.6，浅灰（n8）偏差最大；
   - Portra 800 增感 2 档：2.2，浅肤色 5.3；
   - Vision3 200T 和 500T（配 2383）：约 2.0，我们的黄色、橙色偏饱和。
   - 原因：我们的片种特性数据来自 filmsim（vkdt），和原版的片种档案有出入。需要逐个对比感光曲线和染料光谱。
3. **相纸曲线形状：** 配 Portra 400 时，Ultra Endura 的灰块比原版亮 1.4–2.4 L，2393 亮 1.7–2.9 L。其他相纸在 1 L 以内。需要对比这两种相纸的特性曲线。
4. **光晕的近处形状：** 亮 6 档的光点紧贴边缘那一圈，我们偏亮（0.70，原版 0.43），往外 2 像素又偏弱。这是两边对小于一个像素的模糊算法不同；亮 4 档时两边基本一致。
   - 改法：把乳剂散射的长尾改成真正的指数核（现在是三个高斯的近似），再重新拟合。
5. **颗粒随亮度的曲线形状：** 各片种平均强度已对齐，但单个亮度、单个颜色上最大偏差约 1.28 倍。在 −4 档以下和 +4 档以上偏差较大。
6. **默认杂散光：** 原版默认 0.03，应用默认 0。实测只影响纯黑，差约 0.3 L，可以不改。
